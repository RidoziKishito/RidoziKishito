### 🚀 Featured Projects

#### 🏥 [VHQA: Hospital QA Benchmark & Multi-Layer RAG System](https://github.com/RidoziKishito/VHQA-RAG)
*   **Stack:** Python, PyTorch, QLoRA, ChromaDB, LLMs (Qwen2.5, Gemma, Arcee-VyLinh)
*   Co-authored a research initiative constructing a 1,110-pair Vietnamese hospital QA benchmark.
*   Engineered a multi-layer RAG pipeline featuring semantic routing and locally fine-tuned lightweight LLMs via QLoRA, achieving 72.55% comprehensiveness and a low 17.00% hallucination rate.

#### 🦺 [PPE Safety Detection System – Edge AI](https://github.com/RidoziKishito/construction-ppe-safety-edge-computing)
*   **Stack:** Python, PyTorch, YOLO26n, ONNX, Modal GPU
*   Fine-tuned YOLO26n across 30k+ safety images leveraging Modal cloud GPUs and exported optimized ONNX runtimes hitting 130+ FPS on edge hardware.
*   Engineered a real-time geofenced rule engine with temporal smoothing to filter out false positives.

#### 🩸 [White Blood Cell Classification – Lightweight Deep Learning](https://github.com/RidoziKishito/WBC-Classification-Lightweight-GAN)
*   **Stack:** Python, PyTorch, OpenCV
*   Investigated lightweight neural architectures and knowledge distillation (teacher-student) pipelines tailored for edge deployment.
*   Tackled extreme class imbalance across Raabin and LISC medical datasets using generative synthesis and 2-stage transfer learning.

#### 🍎 [Nutrition Tracker – AI Meal Logging App](https://github.com/RidoziKishito/calorie-tracker)
*   **Stack:** FastAPI, PyTorch, PostgreSQL, Supabase, EfficientNet-B3
*   Full-stack meal logging and calorie tracking platform integrating vision-based food recognition.
*   Managed real-time inference pipelines, authentication, and user dietary metric calculations (BMI/TDEE).

#### 🕹️ [Reinforcement Learning: Flappy Bird DQN](https://github.com/RidoziKishito/flappy-bird-dqn)
*   **Stack:** PyTorch, Pygame, OpenAI Gym concepts
*   Engineered a Flappy Bird game environment coupled with a Deep Q-Network (DQN) agent learning navigation policies directly from gameplay states.

#### 🔊 [Industrial Acoustic Anomaly Detection](https://github.com/RidoziKishito/VIVOS-DEMAND-Speech-Enhancement)
*   **Stack:** Python, GMM/DAGMM, Flask, MIMII Dataset
*   Unsupervised anomaly detection pipeline designed to flag operational failures in industrial pumps from acoustic signals, accompanied by an interactive Flask web demo.
